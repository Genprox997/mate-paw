# 桌面宠物角色姿势生成 · 提示词模板（多人版）

> 用途：用**一张多人照片**，先拆出图中每一个人，再为每个人生成桌面宠物所需的三个姿势精灵图（爬行 / 坐下 / 挥手），并**严格保留每个人真实的长相、发型与服装**，自然补全双手、双腿及被遮挡的部分。

---

## 0. 一键流水线（推荐，去掉所有手动环节）

`pose_pipeline/pose_pipeline.py` 把上面的手动步骤串成两条命令，无需手动裁图、手动写外观、手动 rembg、手动归档：

```bash
# ① 自动检测并裁剪图中所有人，生成任务清单（依赖 ultralytics；未装时可用 --n N 三等分回退）
python pose_pipeline/pose_pipeline.py detect <多人照片.png>
# ② （由 Agent / ImageGen 对 pose_pipeline/stage2/todo.json 逐张出图，见下方说明）
# ③ 生成完成后，一键抠图 + 合成 768x1024 透明画布 + 落盘
python pose_pipeline/pose_pipeline.py compose
```

- 阶段一用 **YOLOv8 自动检测**所有人并单人裁剪（不再手动数人数三等分）；裁剪图直接作为图生图参考，靠 `input_fidelity=high` 保身份，**无需手动写外观描述**。
- 中间生成由 Agent 读取 `pose_pipeline/stage2/todo.json`（含每人每姿势的 `prompt` 与 `crop` 路径）**顺序**调用 ImageGen：`size=768x1024, background=transparent, input_fidelity=high, quality=high`，结果存为 `pose_pipeline/stage2/<out>`。
  > ⚠️ **必须顺序生成，不要并行**：ImageGen 并行调用会互相覆盖同一路径，且极易触发 `RequestLimitExceeded.JobNumExceed / 150 个任务上限` 的限流。每出一张立即重命名，再继续下一张。
- `compose` 自动 `rembg` 抠图（白色外套安全）+ 居中合成透明画布，落盘到 `mate-paw/res/<id>/`。

> 完整脚本与参数见 `pose_pipeline/pose_pipeline.py`；下文 §3–§7 是流水线内部使用的模板与参数细节，可对照阅读。

---

## 1. 目标与总体思路

- **输入**：一张含多人的照片（合影、合照、工作照均可）。
- **输出**：图中**每一个人**各 3 张姿势图 —— 爬行、坐下、挥手。
- **核心原则：先「拆人」，再「造姿势」。**

  > 关键教训：ImageGen 的「图生图」一次擅长处理**单一清晰主体**。把一张多人合影直接丢进去，模型通常会只保留一个人、或把几个人特征混在一起。**必须先逐人裁剪/分割为单人干净图，再对每个人单独跑三套姿势模板**，才能保证「每人各一套、长相不串」。

---

## 2. 工作流（总览）

```
多人照片
   │
   ├─ 阶段一：人物提取（多人 → 单人干净图）【脚本自动：YOLOv8 检测 + 裁剪】
   │     检测图中所有人 → 逐人裁剪 → 单人图（crop 直接作为图生图参考，靠保真保身份）
   │
   ├─ 阶段二：逐人姿势生成（单人图 → 三姿势）【Agent 顺序调用 ImageGen】
   │     对每个人分别用 爬行 / 坐下 / 挥手 三个模板出图（参数一致）
   │
   └─ 阶段三：后处理 + 落盘（脚本自动：rembg 抠图 + 合成 + 归档）
         抠图 → 居中合成 768x1024 透明画布 → 落盘到 mate-paw/res/<人物id>/
```

> 上述三步已由 `pose_pipeline/pose_pipeline.py` 串成 `detect` →（生成）→ `compose`。手动环节仅剩「调用 ImageGen 出图」一步（由 Agent 完成）。

1. 准备一张多人参考照片（合影 / 合照 / 工作照，全身正面、背景简单为佳）。
2. 运行 `python pose_pipeline/pose_pipeline.py detect <照片>` 把所有人拆成单人图、生成 `stage2/todo.json`。
3. 由 Agent 读取 `todo.json`，对每张 **顺序**调用 ImageGen 出图，保存到 `stage2/`。
4. 运行 `python pose_pipeline/pose_pipeline.py compose` 自动抠图、合成、归档。

## 3. 阶段一：人物提取（多人 → 单人）

目标：从一张图里得到「图中每个人各自的单人干净图」。`detect` 默认用 **YOLOv8 自动检测**完成，下面两种是回退方案（对应脚本的 `--json` / 手动裁剪）。

### 3.1 提取方式

- **方案 A · 脚本自动（默认，推荐）**：直接 `detect <照片>`，YOLOv8 检测所有人并按从左到右裁成单人图，无需任何手动操作。
- **方案 B · 视觉模型描述 + 裁剪（`--json` 回退）**：若自动检测不准（人贴太近 / 严重遮挡），把原图交给多模态模型返回 `bbox` + `appearance` 的 JSON，再用 `--json persons.json` 走同一流程（见 3.2–3.3）。
- **方案 C · 手动裁剪（兜底）**：直接用画图工具把每个人裁成单人图放到 `stage1/`，跳过检测（此时需自行保证 `todo.json` 存在）。

### 3.2 视觉模型「提取 + 描述」提示词（方案 B 用）

把原图交给支持看图的多模态模型，用下面这段提示词，让它返回结构化结果：

```text
你是一张多人照片的分析助手。请检测照片中的每一个人，并严格输出 JSON 数组（不要输出其他内容）。

对照片里的每一个人，输出一个对象：
- "id": 从 1 开始的整数编号
- "bbox": [x1, y1, x2, y2] 像素坐标，尽量贴身框选（必须包含头发顶部和脚底）
- "appearance": 一段英文外观描述，用于在另一张图里还原该人，需包含：
    face（脸型、肤色、五官特征）、hair（发型、发色、长度）、
    top（上装颜色、款式、图案/logo）、bottom（下装）、shoes（鞋）、
    accessories（眼镜/帽子/背包/首饰等）、以及任何显著特征

规则：
1. 不要遗漏任何一个人（包括被遮挡、在边缘、较小的人）。
2. 描述要足以在全新的姿势图里还原该人，但不要加入任何姿势/动作要求。
3. 若某人被严重遮挡，基于可见部分做合理推断并注明。
```

返回示例：

```json
[
  {"id": 1, "bbox": [120, 40, 360, 900], "appearance": "Asian woman, round face, light skin, black shoulder-length straight hair, wearing red hoodie with white logo, blue jeans, white sneakers, no glasses."},
  {"id": 2, "bbox": [400, 30, 680, 910], "appearance": "Asian man, square face, tan skin, short black hair, black round glasses, grey t-shirt, black shorts, red trainers, carrying a blue backpack."}
]
```

### 3.3 裁剪脚本（方案 B 用）

拿到上面的 JSON 后，用 Pillow 把每个人裁成单人图：

```python
import json
from PIL import Image

photo = Image.open("1.png").convert("RGB")
data = json.loads(open("persons.json", encoding="utf-8").read())

for p in data:
    x1, y1, x2, y2 = p["bbox"]
    crop = photo.crop((x1, y1, x2, y2))
    crop.save(f"stage1/person_{p['id']}.png")
    # 同时把 appearance 存成同名的 .txt，供阶段二复用
    open(f"stage1/person_{p['id']}.txt", "w", encoding="utf-8").write(p["appearance"])
```

> 阶段一产出的 `person_<id>.png` + `person_<id>.txt` 即为阶段二的输入。

## 4. 通用提示词结构（阶段二）

每条姿势提示词 = **指令 + 身份保留 + 姿势描述 + 背景处理 + 补全 + 质量/尺寸**。

- **指令**：`Photorealistic image-to-image transformation of the reference photo.`
- **身份保留（核心，务必锁死）**：
  `Keep the EXACT same real person from the reference: identical face, skin tone, facial features, same <发型/发色>, same <上装 颜色/款式/图案>, same <下装>, same <鞋>, same <配饰>. Do NOT change identity, do NOT swap with another person, do NOT convert to anime, illustration, cartoon, or 3D render. Maintain realistic photo style and natural lighting.`
- **背景处理**：`Remove the original background and all surroundings. Use transparent background.`
- **补全（用户重点要求）**：
  `Naturally and plausibly reconstruct any occluded or missing body parts — hands, fingers, arms, legs, feet, and any clothing hidden behind objects or other people — so the full body is complete and anatomically correct for the pose.`
- **质量/尺寸**：`High quality, clean edges, 768x1024 pixels.`

> 关键经验：第一版没加 `Do NOT convert to anime/illustration/cartoon` 会被生成成插画风；务必强调 **photorealistic / real photo**。多人图尤其要加 `Do NOT swap with another person`，防止串脸。

## 5. 三个姿势模板（对每个人分别调用）

> 占位符说明：`<外观描述>` 是脚本自动填充的「身份段」占位。若 `detect` 时通过 `--json` 提供了 `appearance`，则展开为 `, same 黑长直发, same 红色卫衣...`；若是自动检测（无外观文本），则整段省略，完全依赖图生图保真保身份。正常流程无需手动填写。

### 5.1 爬行 / 蹲伏（对应 `<id>.png`）

```text
Photorealistic image-to-image transformation of the reference photo.
Keep the EXACT same real person from the reference: identical face, skin tone, facial features<外观描述>.
Do NOT change identity, do NOT swap with another person, do NOT convert to anime, illustration, cartoon, or 3D render. Maintain realistic photo style and natural lighting.
Transform the person into a desktop pet crawling pose: crouching on all fours, both hands and both feet touching the ground, back roughly horizontal, head up looking forward, full body visible from a slightly raised front-side angle.
Remove the original background and all surroundings. Use transparent background.
Naturally and plausibly reconstruct any occluded or missing body parts — hands, fingers, arms, legs, feet, and any clothing hidden behind objects or other people — so the full body is complete and anatomically correct for the pose.
High quality, clean edges, 768x1024 pixels.
```

### 5.2 坐下（对应 `<id>_sit.png`）

```text
Photorealistic image-to-image transformation of the reference photo.
Keep the EXACT same real person from the reference: identical face, skin tone, facial features<外观描述>.
Do NOT change identity, do NOT swap with another person, do NOT convert to anime, illustration, cartoon, or 3D render. Maintain realistic photo style and natural lighting.
Transform the person into a desktop pet sitting pose: sitting on the ground, knees bent up or cross-legged, both hands resting naturally on the knees or beside the body, torso upright, looking forward, full body visible.
Remove the original background and all surroundings. Use transparent background.
Naturally and plausibly reconstruct any occluded or missing body parts — hands, fingers, arms, legs, feet, and any clothing hidden behind objects or other people — so the full body is complete and anatomically correct for the pose.
High quality, clean edges, 768x1024 pixels.
```

### 5.3 挥手（对应 `<id>_wave.png`）

```text
Photorealistic image-to-image transformation of the reference photo.
Keep the EXACT same real person from the reference: identical face, skin tone, facial features<外观描述>.
Do NOT change identity, do NOT swap with another person, do NOT convert to anime, illustration, cartoon, or 3D render. Maintain realistic photo style and natural lighting.
Transform the person into a desktop pet waving pose: sitting on the ground cross-legged, right hand raised high and waving hello, left hand resting naturally on the leg, friendly expression, looking forward, full body visible.
Remove the original background and all surroundings. Use transparent background.
Naturally and plausibly reconstruct any occluded or missing body parts — hands, fingers, arms, legs, feet, and any clothing hidden behind objects or other people — so the full body is complete and anatomically correct for the pose.
High quality, clean edges, 768x1024 pixels.
```

## 6. ImageGen 调用参数

| 参数 | 取值 | 说明 |
|------|------|------|
| `image` | 阶段一产出的单人图 `person_<id>.png` | 图生图输入，提供该人长相/服装基准 |
| `prompt` | §5 中对应姿势模板 | 描述目标姿势与约束 |
| `size` | `768x1024` | 与现有素材一致的竖图比例 |
| `background` | `transparent` | 尽量透明，实际仍需 rembg 兜底 |
| `input_fidelity` | `high` | 高保真，贴合原图人物 |
| `quality` | `high` | 高质量 |

> 同一人的三张图务必保持 `input_fidelity=high` 与相同身份段，确保三姿势是同一个人。

## 7. 后处理：去背景（必须）

生成图背景常为灰白、且不带真透明通道；人物常穿**白色外套**，普通亮度阈值会误删衣服。统一用 `rembg`：

```python
from PIL import Image
from rembg import remove

src, dst = "生成图.png", "mate-paw/res/<id>/<id>.png"
remove(Image.open(src).convert("RGBA")).save(dst)
```

输出应为 RGBA、768×1024、背景透明（程序按文件名排序，第一张为默认姿态）。

## 9. 批量串联（已由脚本实现）

上面 §5 的三套姿势、§6 的 ImageGen 参数、§7 的抠图，已封装进 `pose_pipeline/pose_pipeline.py`：

- `detect`：检测 + 裁剪 + 生成 `stage2/todo.json`（含每人每姿势的 `prompt` / `crop`）。

无需再手写上面的循环；唯一注意点仍是 **ImageGen 必须顺序调用**（见 §0 警告）。

## 10. 常见问题与经验教训

- **多人图直接丢给 ImageGen → 只出一个人/串脸**：必须在阶段一先拆成单人图，逐人生成。
- **被生成成插画/卡通风**：务必在身份段强调 `photorealistic / real photo / Do NOT convert to anime, illustration, cartoon, or 3D render`。
- **白色外套被去背景误删**：必须用 `rembg` AI 抠图，禁用亮度阈值。
- **四肢/遮挡补全不到位**：在「补全」段明确列出 `hands, fingers, arms, legs, feet` 及「被物体或他人遮挡的衣物」，并要求 `anatomically correct for the pose`。
- **同一人三张不一致**：三张共用同一身份段 + `input_fidelity=high` + 相同参数。
- **某人被严重遮挡**：阶段一让模型基于可见部分合理推断外观并标注，生成时仍以「补全」段兜底。
